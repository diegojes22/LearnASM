Hola, en este reositorio he coloocado todos los codigos y ayudas que he escrito en **Ensamblador** (ASM) para la materia de **Lenguajes de Interfaz**. Todo lo que esta aqui puede ser visto por cualquier persona, aunque este repositorio esta dirigido y echo principalmente por y para alumnos del **TecNM** que cursen la materia de **Lenguajes de Interfaz** y que, para colmo su profesor tenga la desdicha de enseñar de forma incorrecta `Turbo Ensamblador`.

### Entorno
Todos los programas escritos y almacenados en este repositorio estan especificamente creados para ejecutarse en un entorno tipo **MSDOS** junto con el ensamblador y el enlazador de **TASM**.

Para la instalacion de dosbox puedes ir al [Sitio web oficial](https://www.dosbox.com/download.php?main=1) y ahi descargas el instalador, o en este mismo repositorio puedes encontrar el instalador para sistemas Windows. Con respecto a al ensambaldor y al entazador de **TASM**, estos se encuentran en la carpeta de `/resources`.
